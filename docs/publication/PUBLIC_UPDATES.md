# 公开内容更新

本次补齐机型与组件索引，加入 X1D II 人脸优先片段，并统一整理全部 Markdown。主要开发仍在独立研究项目，公开仓用于展示经筛选的源码。

## 主要内容

- X2D 像素位移面阵扫描合成：四／六个位置采样的空间重建、并行分批读取、后台写入、通用内存双路消费及图像工具。
- 首页分别说明 X2D 对焦、人脸／人眼目标优化与电子快门闪光研究，并列出第一代 X1D 和 X1D II 的主要方向；用途与验证状态分开描述。
- 左右眼选择、灰度模板跟踪、显示控制说明与原创离线界面。
- X1D II 目标选择、状态交换和发布器片段；发布器仍缺四个项目头文件。
- 固定版本 libfacedetection，保留 BSD-3-Clause 及同版本公开模型参数；四份源码及 LICENSE 与上游逐字节一致。

首页、机型 README、构建与状态说明已同步。旧文档改为主题摘要，移除内部地址、设备记录、私人路径与施工交接；规则文件和第三方声明保留必要内容。

## 验证与限制

像素研究已完成普通内存与固定文件算法对照，覆盖跨批次、双路消费、失败释放和背压，另有十个 C 组件和十一项 Python 检查。X1D II 检测库独立编译及自造空白 BGR 图调用通过，不代表发布器、检测质量或真实对焦通过。

方法见 [构建说明](../build/BUILDABILITY.md)，来源见 [像素审核](../../publication/x2d-update-review.json)和[X1D II 与文档审核](../../publication/x1dii-update-review.json)。
