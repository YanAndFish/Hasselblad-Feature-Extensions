# 机内 AF 设置候选 r1

本目录与历史 observation r1 隔离。本任务完成离线开发和验证，没有发送 USB 请求或触发真实 AF。`installed-baseline/source-manifest.json` 冻结旧版本的源码、构建与恢复输入；它记录历史安装，不证明换电重启后仍驻留。现场装载由主任务独占执行，当前交接见 `INSTALL_HANDOFF.md`。

最终参数以 `PARAMETER_CONTRACT.md` 为准：判向、快扫、精扫默认全部跟随原厂，人工档位分别为 5000/7000/9000/11000/13000、5000/10000/15000/20000、3000/4000/5000/6000/7000。机内页面通过已有通信通道读写配置，设计为拔掉 USB 后可用，目标 Qt/IPC 尚待现场验收。抗噪判向默认关闭。一次 AF 开始时采用完整配置，正在进行的一轮继续使用已锁定配置。精扫状态机继续执行原厂流程。

快扫切换提前量与精扫停止提前量是两个独立的绝对毫秒值。原厂速度下也可单独保存人工值；切档恢复目标档预设，恢复原厂撤销覆盖。尚无经过验证的人工档预设，所以显示未标定，不能填入猜测值。两项实际提前动作未接通，能力位均为 0；保存、回读和下轮锁定不代表已经提前减速或停止。

后续样本必须持续滚动参加判断。第三个样本没有结论不结束判向；第四、第五及后续新样本继续计算。保留原厂搜索边界、超时和精扫交接，不把窗口容量当作整个 AF 的帧数上限。

## 已核对的事实

- 固定来源是 X1D 1.25.0 FARM，SHA-256 `317841f6f4dff599cda8c83f2b4912f78534db20e7690d0b14b0cd5f1b8c39ca`。地址结论都绑定这个版本。
- `0x19e47c` 在 accepted count 大于 2 时，读取最近三个已接受 CV。两段严格同向变化才给出方向指标。状态 3 会再次调用，并非前三个失败就永久停止。`0x19d19c` 还检查变化阈值、亮度相关门限和较多样本时的统计过滤。
- accepted 不是所有视频帧：`0x1a2a30` 配对 CV 与镜头位置 FIFO；方向改变会清空计数，估计速度超出当前命令容差会丢弃样本。数组容量 500 是容量/错误边界，不能说是一次 AF 的固定帧数。
- 历史 observation r1 安装回执中新判向和速度覆盖均关闭，`na_supply` 没有真实采样供应者。其离线 3/4/5 样本规则不能声称是相机实际运行的新算法。新设置候选改从原厂 accepted 数据读取滚动窗口；这仍不是物理同帧关联的证明。
- 原厂 `0x1a0240` 把命令作为 signed16 放入 `0xCD` 消息；20000 可编码，FARM 本段没有饱和截断。这不证明镜头达到 20000 的物理速度。
- 共享 XCD55V 1.9.11 包内的 **XCD75P 专用参数**参考系数为 0.20768000185489655。按已研究的零附加修正公式，20000 × 4 × 系数约为 16614，超过参考驱动限幅 16000。当前镜头驱动固件未读回验证；不能绕过此限制，也不能把参考模型当作实际转速。

## “跑到最近端”的证据边界

现有证据是用户观察，根因未定位。用户已取消新增图像/SD 采样安排；本轮沿用原有 18 张图片，已复核 36 张派生输入和 48 组局部策略检查，不安排新增采集。它们不构成真实时序标定。

原有记录器可区分 raw CV、CV/位置 FIFO、accepted count 和阶段命令，但没有记录每次方向指标、丢样本原因、端点事件，尾部也可能覆盖起始数据；缺失记录只能标为未知。FIFO 配对不是同一曝光时刻的证明，入口 tick 也不是传感器曝光时间。本说明不安排读取相机记录。

机内 UI 必须显示待应用与本轮配置的真实回执。预判时间被保存与预判实际介入需要分别呈现；同帧关联、延迟和制动参数尚未验证时，不能仅靠开启按钮宣称预测制动已经可用。
