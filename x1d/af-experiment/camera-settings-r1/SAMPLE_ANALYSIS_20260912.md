# 18 张实拍样本的 AF 几何代理与局部判向检查

本轮完成 18 张原图的只读解码、36 个派生 PNG、三种重采样下的两项评分，以及 48 组真实 ARM 局部判向回放。原图 SHA-256 全部保持不变；没有访问设备、安装、AF 或拍摄操作。结果可复现，但不是实机 LV、FPGA CV 或完整 AF 成功率测试。

用户确认：三组均从清晰开始，每拍一张手动将对焦距离向近处调一点；使用最中心位置和大框。不限定场景距离。按[联系表](build/sample-analysis-20260912/contact.png)逐图核对，分组如下，并非每组六张。

| 场景内容 | 文件范围 | 张数 | 中央框核对 |
|---|---|---:|---|
| 杆端 | B1489470–B1489477 | 8 | 杆端逐渐模糊，位置和覆盖有所变化 |
| 盒角 | B1489478–B1489482 | 5 | 盒角、亮墙与暗盒面混合进入框 |
| 电线 | B1489483–B1489487 | 5 | B1489484 明显改变构图，中央框落在墙面，单独标记 |

原图都是 4128×3096、RGB JPEG。未提取或导出 EXIF。文件名、尺寸和校验仅用于这次用户要求的样本追溯；[来源表](build/sample-analysis-20260912/sources.json)保留逐图哈希。

## 原生输入合同与代理边界

固定来源为官方 X1D 1.25.0 FARM，SHA-256 `317841f6f4dff599cda8c83f2b4912f78534db20e7690d0b14b0cd5f1b8c39ca`。普通 AF 内部 mode 5、sensor mode 8，12 bit，输出 2756×476；前级边缘处理后统计坐标为 2748×468。[已有管线核对](../FAST_AF_160_RESEARCH.md)包含尺寸来源与替身范围。本轮重新在隔离 ARM 内存执行原厂 `0x1f0090`，中央位置 5000/5000、尺寸 900/1200 万分比，得到 x=1250、y=206、宽248、高56；[验证记录](build/sample-analysis-20260912/validation.json)绑定结果与来源。

这是 AF 统计几何，不能称为已采集的显示 LV 帧格式。已有 640×360 显示参数来自离线模型输入。实际显示输出布局、像素总线 packing、FPGA A/B 空间核、与本次 JPEG 的精确光学边界均未重建；没有足够证据把语音中的 LY/RY 定义为某种真实格式。

当前机内算法也不直接接收这些 PNG。原生 CV 中断读取两通道，模式 1 得 `uint(A+0.25×B)`，经独立 CV/位置 FIFO 及速度筛选后形成标量 CV、位置接受数组。局部判向使用这些标量。两通道不能直接等同本报告的梯度和 Laplacian 能量。

派生方法固定为：JPEG 像素转 8 bit 灰度（Pillow RGB→L，保留 JPEG 的非线性亮度关系）→整幅 BOX 面积重采样为 2748×468→裁中央 248×56。保存灰度全幅与 ROI PNG，不携带原图元数据。统计坐标像素不是方形光学采样单元；[ROI 联系表](build/sample-analysis-20260912/roi-contact.png)仅为审阅而恢复近似方形显示。另计算 BILINEAR 和 NEAREST 敏感性结果；NEAREST 也不是真实传感器抽行仿真。

4 mm 大框与上述归一化框的对应由用户所选大框及已有 GUI 常量支持；没有把 4 mm 直接换算为未经验证的感光像素。JPEG 锐化、降噪、色调、曝光以及实际读出采样差异均可能改变评分，因此没有把 L8 扩为 12 bit 后冒称原生 RAW。

## 评分结果

主方法为 BOX。下表均相对本组首张，顺序来自用户确认的拍摄过程，而非从文件名推断镜头方向。

| 场景 | 梯度能量相对序列 | 观察 |
|---|---|---|
| 杆端 | 1.000, 0.440, 0.332, 0.208, 0.147, 0.117, 0.078, 0.064 | 梯度持续下降；Laplacian 到末段接近平坦并小幅回升 |
| 盒角 | 1.000, 0.272, 0.252, 0.181, 0.214 | 最后一张回升约18%，三种重采样均有此现象，不能简单断言纯模糊度单调 |
| 电线（保留全部） | 1.000, 0.069, 0.096, 0.063, 0.054 | 第2张构图异常，后续回升混入内容变化 |

三组首张在两项指标、三种重采样中均最高。电线组排除构图异常张后，梯度为 1.000、0.096、0.063、0.054，单调下降；异常张仍保留在原材料和完整结果中。没有移动 ROI 来人为追随主体。图像内构图变化、调焦引起的画幅变化与内容占比变化未分离，不能将盒角末张回升归因于某一个原因。

## 局部策略结果与含义

[ARM 回放](build/sample-analysis-20260912/policy-results.json)使用当前独立候选 `na_direction` 和原厂 `0x19e47c` 的实际机器码。将代理能量乘256并量化为整数，再注入接受数组。仅以**每张 +20 的合成位置间距**检查趋势；用户确认向近侧，固定 FARM 静态符号正数指向近侧。真实镜头位置、每次调焦幅度和时刻未知。

| BOX 梯度序列 | 原厂 helper 首次通过绝对值0.2 | 新判向首次通过绝对值0.2 |
|---|---:|---:|
| 杆端 | 第3张，向远侧 | 第4张，向远侧 |
| 盒角 | 第3张，向远侧 | 第4张，向远侧 |
| 电线，全部 | 第5张，向远侧 | 第5张，向远侧 |
| 电线，排除构图异常张 | 第3个保留样本，向远侧 | 第4个保留样本，向远侧 |

新判向前三张未通过，主要是首次下降远大于随后下降，触发相邻空间斜率比限制；它继续滚动而没有永久放弃。真实手动间距未知，这里不足以判断该限制应当放宽。两项代理的末段结果也不同：Laplacian 更早接近平坦，容易落到门限以下。

这些“通过”仅指局部 helper 与绝对值门限，未执行原厂亮度下限、7点起的统计过滤、FIFO接受、马达运动、越峰、精扫或停机状态机。48组均未产生向近侧的局部门限决定，仍不能据此报成功率、最佳速度、实际帧数、耗时或停止提前量。尤其本批只有离开清晰起点的一侧轨迹，没有穿越峰值再返回的记录，无法验证“越过最清晰处不停车”的实机现象。

这批材料支持把内容变化、低信号末段和三帧拒绝后继续滚动列入回归检查；它没有证明机内 ROI 或 FPGA 评分损坏，也不足以调定 10000/20000/5000 的物理速度和额外提前停止毫秒数。

## 复现

在本仓库根目录执行。图像处理使用已核实的 Python 3.12 + Pillow/NumPy；绘图额外使用本 AF 模块已有的 matplotlib 包目录。ARM 检查使用项目已核实的 Unicorn/FARM 加载工具。命令都不导入 USB 接口。

```powershell
& '%USERPROFILE%\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -B x1d/af-experiment/camera-settings-r1/CodeTests/prepare_sample_contact.py
& '%USERPROFILE%\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -B x1d/af-experiment/camera-settings-r1/CodeTests/analyze_samples.py
python -B x1d/af-experiment/camera-settings-r1/CodeTests/check_sample_policy.py
python -B x1d/af-experiment/camera-settings-r1/CodeTests/verify_sample_artifacts.py
```

[scores.json](build/sample-analysis-20260912/scores.json)含全部原图／派生关联和数值；[score-summary.json](build/sample-analysis-20260912/score-summary.json)含各方法的相对序列。验证完成18份原图不变、36份派生哈希、48组局部回放绑定及原生中央ROI重算。未改动已装观察候选或任何合并 UI、回放、引闪文件。
