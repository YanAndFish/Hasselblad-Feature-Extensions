# AF r7 离线实现状态

本目录仅为独立 AF 的离线实现与验证，当前不能作为相机安装包。机身分析固定为 X1D 1.25.0，FARM SHA-256 为 `317841f6f4dff599cda8c83f2b4912f78534db20e7690d0b14b0cd5f1b8c39ca`。本轮设备请求为 0，未安装、对焦、拍摄或读回当前参数。

## 已接通的逻辑

- 测试版低速起步可显式选择“镜头报告 ×70%”，同时设为 10 个有效样本。报告速度仅从原厂成功接收的动态参数缓存读取，不发额外查询。选择后需点击保存；手动速度仍保留。
- 同一轮低速只执行一次；原厂判向成立时直接进入原厂快速扫描，优先于低速样本数到达后的高速恢复。端点反向及重试不会重新开始低速。
- 原厂 `UNKNOWN` 写入后使私有身份失效；原厂 `NEW LENS` 发布后记录识别三字节与完整动态参数行。使用时检查发布代次、机身型号、当前归一化焦段和缓存内容。观察桥不修改原厂识别结果。
- 精扫提前量作用于原厂下降确认等待窗口。根据有效样本到达间隔估算剩余确认时间，已有下降且落入预算时发出原厂同一个 `0x40`，沿用原厂端点标志语义。零值和“原厂”选项执行完整原函数；原厂验峰、精扫和停止核心保留。
- 抗噪实验判向入口已移除；测试版保留手动配置和观察记录，发布版不编入这些运行代码或 UI。

## 提前量的时间口径

原厂 `0x11d704` 含 `WaitForSingleObject` 日志。其 `0x11d728..0x11d75c` 将输入乘 1000、除 1000，再加 `0x188624` 返回的调度 tick；实际 ARM 回放验证 0、1、50、100、1000 的转换。该兼容接口的超时单位为毫秒，参见 [Microsoft 参数定义](https://learn.microsoft.com/en-us/windows/win32/api/synchapi/nf-synchapi-waitforsingleobject)。另已定位定时器重装值 200000 与 tick 递增链。

这里使用固件调度时间，并非曝光时间或实测精度保证。模拟每 50 ms 接受一份 CV `100,150,200,190,180,170`：原厂在 300 ms 发出 `0x40`，设置 100 ms 时在 200 ms 发出。其他采样间隔下提前量受有效样本粒度和已有下降证据约束，不能宣称每轮物理上都恰好提前 100 ms。用户“实测可行”的反馈作为用户观察保留，不等同于本版实机验证。

## 离线证据

`CodeTests/output/r7-core-contracts.json` 绑定核心、身份、起步、原厂流程与安装契约测试结果及源文件摘要。八组动态参数成功/失败回放使用模拟回复，验证机身路径；并非镜头完整通信或启动流程验证。

`CodeTests/output/qml.json` 记录 426 项 Qt 6.11.2 真实指针检查，涵盖三个尺寸和两种入口。界面库使用 Qt 5.5 公共头编译，但尚未在相机的 Qt 5.5 运行。`CodeTests/output/ui-auto.png` 为自动低速选择截图。

安装契约要求显式指定 `test` 或 `release`，校验已审来源、精确分支和原厂分配结果。测试版 16 个入口，发布版 12 个入口；两者有各自的同步执行确认位置。完整安装与恢复模拟使用原厂 ARM 分配器、真实 Python 流程和外设替身；恢复保留堆块，不释放。当前安装和恢复 loader 均拒绝硬件 IO。

## 尚未完成

发布策略仍保持 `eligible=0`。八支镜头高速段和快速扫描的最终命令标度尚未核清，不能把镜头内部 raw 值直接作为机身命令。发布白名单、无增距条件与最终策略还需接合验证。快速扫描提前字段仍是保存项，尚未接入新提前执行逻辑。

旧 `inputs/`、组合脚本、非 profile 的 `build/` 和旧验证入口是继承材料，尚未形成 r7 完整交付包，不可据此安装。当前有效原生构建在 `build/test/` 与 `build/release/`。完成最终策略后还需刷新来源锁、组合包和独立验收；四模块合并及持久自启动不在本轮完成范围。
