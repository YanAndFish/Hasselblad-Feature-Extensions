# 用户实测后的修正范围

2026-09-14 用户确认：所有镜头使用新版对焦规则；仅八支指定镜头额外使用新速度配置。规则启用不能与速度白名单绑定。用户实测 90V、75P 均表现为原厂规则和速度，当前版未通过这两支的用户验收。

八支为 25V、38V、55V、90V、28P、75P、20–35E、35–100E。高速段和快扫段应使用各镜头的最大速度；75P 的目标命令值为用户明确指定的 20000。其余七支最大命令值不可用镜头参数表原值或统一倍数代替未经验证的结论。

代码已确认的问题：release_policy.c 未设置 probe/fast，零值使其沿用原厂命令；native_adapter.c 的 valid 同时限制速度覆盖和提前确认，导致白名单失败时二者同时停用。发布版没有编译 rolling_direction.c，其判向调用保持原厂。因此不能把程序装载成功表述为全部新规则已生效。

用户已再次明确：新版规则是低速起步判向、高速继续判向、快扫找峰、精扫确认及提前预算；抗噪判向算法继续关闭。10 个有效采样未判向则切高速，提前判向则直接快扫。规则对所有镜头启用，只有速度配置按八支白名单区分。

本轮正在做本地修正，尚未将后续修正版装入相机。当前相机仍是先前临时 release 版本；不做未经协调的原位覆盖。
