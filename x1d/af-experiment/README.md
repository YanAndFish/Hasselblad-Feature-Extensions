## 判定使用多少帧

最少使用 **5 个有效且有位置间隔的清晰度样本**，不是简单数 5 张传感器帧。重复位置、尚未被原厂接受的样本不凑数；原厂的位置与 CV 配对、实际速度容差筛选仍在前面运行。

五点窗口要求最近三个下降幅度分别超过噪声阈值，且相对起点累计下降至少约 4% 或六倍噪声。证据不足时可在既定行程预算内滚动窗口。满足后只通过原厂速度函数反向一次；此时不立即宣布发现边缘。

回程须等待原厂方向／样本数组复位，再看到至少三个新位置样本形成两次足够的上升，并恢复到起点清晰度附近、位置回到起点一个采样间隔以内，才发出原厂第一边缘事件；后续第二边缘和拟合保持原厂处理。

保护包括：指定镜头档位 18、无速度覆盖、三处速度一致、当前 AF 状态与方向、曝光参数／ROI／帧率等配置一致、有效样本上限、数值范围与距离预算。去程和回程各有 250 个 RTOS tick 的预算；本轮读取观察到 tick 约每毫秒增长一次，这不是硬件精密时序测量。退出候选后继续原厂流程，不等于整个原厂 AF 必须在该预算内结束。

正常 AF 的约 97.75 Hz 是此前固定固件的静态时序推导。即使连续有效，五点首尾名义跨度约 40.92 ms，也不包含启动、丢弃样本、镜头加减速与回程。阈值尚未用大量 75P 实测场景校准；照明变化可能形成类似清晰度轨迹，当前没有逐帧曝光元数据配对证明。
