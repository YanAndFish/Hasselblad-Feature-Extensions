## 使用入口与配置

打开 [独立测试界面](ui/index.html)。完整 `ui/` 目录包含所需脚本、内嵌 WASM 和数值输入，无 CDN、设备接口或配置上传。当前本地预览为 [AF 测试](http://127.0.0.1:8817/index.html)，浏览器内另有 [验证范围与图表](ui/validation.html)。

本次已验证通过仅绑定 `127.0.0.1` 的静态服务访问。内置浏览器安全策略阻止 `file://` 导航，未验证直接双击 HTML 的打开方式，也未绕过此限制。需要重新启动预览时，在项目根运行 `python -B -m http.server 8817 --bind 127.0.0.1 --directory .\x1d\af-experiment\ui`；仅服务界面目录，不服务整个仓库。

[独立界面 ZIP](build/native-af-r1/XCD75P-AF-offline-test.zip) 包含完整界面、内嵌模型、图表、中文使用说明和逐文件哈希；由 [白名单打包脚本](build_native_ui_package.py) 核对当前 ARM/UI 检查、图表及数值输入后产生。详情见 [包清单](build/native-af-r1/ui-package.json)。

三个选择器分别控制判向试探、方向确认后的快速 AF、越峰后精扫；每段独立提供 `跟随原厂 / 1000 / 2000 / 3000 / 5000 / 8000 / 12000`。它们是实验协议命令幅值，不是 RPM、物理速度或已验证机械范围，也不是已经调好的三档定版参数。

`新判向` 默认关闭。ARM 候选关闭时真实调用原厂 `0x19e47c` 判向 helper，后续门限、统计过滤与方向事件仍由原厂执行；阶段速度和预判独立生效。开启时使用本文的空间趋势候选。不能把关闭开关理解为所有行为均恢复原厂。

配置使用带版本与校验的 36 字节完整快照。单一接收者发布到 pending；每个 AF 周期开始时锁定 active，同一周期不接受半途修改。三个阶段和开关一起生效；无效镜头标签、档位、标志、旧版本、半包和忙状态均拒绝。这里只验证离线配置协议，尚无实机配置传输与并发接收入口。

“导出待用配置”保存 pending；“导出本轮记录”和 CSV 保存本次 active、实际命令、模型条件、轨迹和备注。修改选项不会重写已有回放。配置导出明确标记 `installable:false`，不把合成速度比例、延迟和制动能力当成相机标定。

## 固件与 75P 依据

全部原厂地址绑定 **X1D 1.25.0 wedge FARM**，SHA-256：

`317841f6f4dff599cda8c83f2b4912f78534db20e7690d0b14b0cd5f1b8c39ca`

它不代表当前相机内存或当前镜头版本。原厂证据由 [静态导出脚本](CodeTests/inspect_native_af_baseline.py) 生成，见 [区域与哈希](build/native-af-r1/native-evidence.json) 和 [反汇编](build/native-af-r1/native-evidence.asm)。当前候选不修改 ROI、传感器模式或 160 行读出，也不再接管完整原厂 AF 状态机。

| 原厂范围 | 当前离线候选行为 |
|---|---|
| state 3，`0x19d1b0` 调用点 | 原厂仍计算最大 CV；按本轮开关选择原厂或增强局部判据 |
| state 4，`0x19d5c8` | 先计算提前降速建议，再完整继续原厂越峰检测；不伪造 `0x40` 事件 |
| `0x1a1f64`；`0x19d41c/0x19d524`；`0x19d944/0x19d9b4` | 分别应用本轮判向、快速、精扫速度，继续通过原厂 `0x1a0240` 封装 `0xCD` 命令 |
| `0x19bbec` 周期重置调用点 | 先执行原厂 `0x1a4950` 清理，再锁定下一轮配置 |

默认 `na_speed_overrides=0`、`allow_actuation=0`，只有离线用例显式开启对应路径。单纯运行 ARM 文件不会形成可安装版本。

档位中的 3000/5000/8000/12000 来自本项目历史命令实验；1000/2000 为低速采样比较新增的编码候选。[速度目录](build/native-af-r1/speed-catalog.json) 绑定了官方共享 `XCD55V_v1_9_11.cim` 包中的 **`LensSpecifics_XCD75P.hex`**，核对其文件哈希、Intel HEX 校验及解码哈希；没有用 55V 专用参数代替 75P 参数。零额外修正参考路径 `12000 × 4 × 0.20768000185489655` 舍入约 9969，低于该软件路径 16000 上限。这只说明参考计算未在这一层溢出或钳制，不能证明物理速度或安全上限。来源材料只读，未改写无线闪光目录。

## 判向与随实际运动变化的预判

前三帧是优先判向窗口，证据不足时继续原厂取样。增强路径用相邻实际位置的 CV 空间差分，检查最近趋势与量化/信号下限；有同帧辅助指标时要求两者同向。主辅指标来自同一图像，具有相关性，不能视为两个独立证据源。单一指标默认至少四帧；可靠双指标可在第三帧提出方向。原厂 0.2 等后续门限仍会决定是否接受。

初版用二次曲线端点导数判向，在凸形下降曲线上会错误外推。当前改用已观察到的空间差分中位趋势，并用实际最近两步跨度形成原厂同量纲的方向指标。延迟不会被用于放大方向置信度。已知噪声或运动不一致时等待；关联信息缺失、时间无效或提供器不匹配时，ARM 局部适配器回退原厂。

本次微调只放宽辅助指标：主指标逐段显著同向保持；辅助最近两段可以有一次不超过信号底限的反向量化/噪声，但合计同向变化须超过四倍底限。真实反向、弱证据及主指标单点突变仍不接管。它是低层 CV 趋势判据，不是物体识别。

每个样本包含 CV、辅助 CV、采样位置、采样/收到时刻、帧号、AF 代次、原厂接受计数及关联标志。适配器还逐项比对原厂已接受的 CV/位置数组，拒绝旧周期、错配或反向后残留。**真实同帧采集入口尚未连接，当前由离线用例提供这些事实。**

预判按位置差/采样时间差估计速度；预测速度取近期中位值、最大观测值、有效在途命令速度上界中的最大者。快速阶段的新命令尚未执行时，不能继续拿试探低速估计提前量；命令代次不匹配或速度上界未知时禁用减速动作。

候选预测视野为一帧间隔、样本年龄、剩余处理时间与命令执行延迟之和，再考虑 `v²/(2a)` 制动距离。样本年龄从采样时刻算起，已经包含画面反馈延迟，不重复累加已过去的处理时间。当前有两种建议：

1. 上升趋势提供“相对 CV 变化不超过 20%”的采样距离预算。20% 是待检验的启发参数，不能命名为实际峰宽或可靠峰位。
2. 至少五点且二次曲线残差/曲率通过时，预测前方局部峰并保留一个观测位置步长。

连续两个不同接受计数给出一致类型的建议后，适配器才可降速；峰拟合还要在一个位置步长内一致。降速不超过现有命令，最小值来自本轮精扫选择或原厂精扫 getter。`0x6bcb7c` 是用于 getter 的字节标志，不能当成精扫速度。原厂反向、越峰事件和精扫流程继续负责后续动作。

## 公开输入与复现边界

历史图像衍生输入、曲线图和对应统计不随本候选分发；旧图像矩阵不能作为本公开版本的验证证据。纯解析测试样本及使用者自行准备输入的方式见 [输入说明](USER_IMAGE_TESTS.md)。完整 AF 构建仍有其他依赖，见项目根目录阶段说明。

当前 ARM 核心镜像 7104 字节，SHA-256 `73bf8bea7ad84e97fe0d7c798611bdc88ba5f577431c999e09b710561853786b`。WASM 5750 字节，SHA-256 `ec74095dc37396d6dd399cf4e51982f3bfea09241cbaf48bb0381b525e88d63e`，本轮未改共享计算核心。Thumb 加 ARM 桥为 5888 字节（text 5458、data 408，含对齐），SHA-256 `98ffbdf74c057c9e15a127122e10324041a298617126b701e2fd8a82c1b3a435`。这两个局部核心构建均链接在仿真地址 `0x800000`，不含本轮三个记录环，不可直接安装；完整观察主体见装载说明，体积不代表相机 RAM 已分配。
