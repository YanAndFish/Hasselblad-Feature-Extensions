# XCD 75P 对焦测试（离线候选）

完整保留本目录及 `evidence/`。当前验证入口是在本目录使用 Python 静态服务：

```powershell
python -B -m http.server 8817 --bind 127.0.0.1 --directory .
```

然后访问 `http://127.0.0.1:8817/index.html`。服务在本机运行，结束时在启动它的终端按 Ctrl+C。当前程序没有设备接口或配置传输，不安装相机、不触发 AF。

三个阶段各自选择命令幅值；`跟随原厂` 的离线示例是 5000/5000/3000，并非相机读回参数。`新判向` 默认关闭。比较开关时保持其他条件相同；比较速度时每次只改一段。

点击“运行离线模型”后，本轮配置完整锁定。改动选择只影响下一轮；导出待用配置与导出本轮记录是两个不同对象。记录中包含实际模型命令、时序、轨迹与观察备注，CSV 为本轮轨迹。

静态原图追加模糊、运动、延迟、噪声与浏览器阶段流程均为模型。模型到精扫交接点停止，精扫使用原厂流程；这里不模拟精扫，不给出精扫耗时、完整 AF 时间或合焦成功。精扫速度默认跟随原厂，第三项只显示配置值。详细结果见 `validation.html`，它从主界面的说明链接在页内弹窗打开；点击“关闭说明”或 Esc 返回，保留当前配置与记录。

直接双击 `index.html` 的打开方式未在本次内置浏览器验证：其安全策略禁止工具导航到 `file://`。已验证的是上面的本机静态服务方式。相机手感测试仍缺真实数据关联、速度/时延/制动标定和装载集成。
