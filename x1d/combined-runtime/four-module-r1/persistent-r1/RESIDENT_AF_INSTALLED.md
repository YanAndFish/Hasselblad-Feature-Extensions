# 独立对焦控制器内初始化候选

已安装到相机，文件校验通过，原进程保持运行，ext4 根分区恢复只读。尚未冷启动验收。用户正常重启后才执行新版。

对焦算法、参数和正文重定位模板未改。控制器内初始化器约 1652 字节；程序和期望正文先批量放入同一个已验证的 32KB 分配，随后在既有 SGI 上下文连续完成正文复制、逐字确认、原厂缓存同步、AF proof、十二个对焦入口发布、完整正文与身份校验和门控恢复。原厂任务中的内存分配仍保留；不从诊断线程调用分配器。

普通冷启动模型 6142 次通信，旧已安装版模型 8326 次；这些不是实测秒数。此次安装前读取的旧版主装载为 87107 毫秒，先前一次约 85015 毫秒。新版实际时间待测。

阶段模型：首次依赖及零区检查 2124，早期缓存探测 204，接收器准备 1551，早期清理 136，批量原厂预检 414，原厂确认 4，缓存准备 208，原厂任务分配 636，等待分配 22，恢复唤醒入口 77，批量窗口启用 6，正文与初始化器上传准备 99，控制器初始化调用和结果确认 57，清理 136，接收器退场 468。

验证：完整模型 20243 项故障检查；ARM 初始化器两个不同基址、1530 项成功/拒绝/逐写入中断检查，执行原缓存函数和原 AF proof；接收器原解码/发送与三个上传窗口测试通过（RTOS 队列等使用 ABI 替身）。文件替换事务五种成功/失败路径通过。机上文件和动态链接自检通过；未执行新版 RAM 初始化、对焦动作或拍摄测试。

分配范围不适合暂时移动上传窗口、或已有未完成记录时使用保留的旧路径。临时窗口全部在同一已验证分配内，并在控制器初始化前恢复到原始堆基址。初始化器不分配内存。旧映射库以相同根分区硬链接保留在 .cache-pair-backup 中，避免替换后无法恢复只读；正常重启前不得删除该硬链接。
