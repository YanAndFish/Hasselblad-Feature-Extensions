# 引闪标定与开机整包候选

状态：标定弹窗、参数通路及两秒提示已构建并临时增量安装；设置持久保存与开机整包仍在待办中。当前目标固件为已核验原厂二进制的 X1D 1.25.0；不泛化到其他固件。

## 用户确认的行为

- 引闪设置新增“延迟标定”按钮，打开小弹窗，分别调整 1/125、1/250、1/500、1/1000、1/2000 秒五档机械快门的绝对等待时间。
- 机械触发起点沿用当前“退出空闲”。中间小档沿相邻锚点按名义曝光时间线性插值；慢于 1/125 秒的档位统一使用 1/125 秒的值。
- 初始值分别为 5.00、5.00、6.30、6.90、6.90 毫秒。10 微秒是输入量化，不是物理精度。原厂动态闪光修正和电子 B 路保持独立。
- 持久版保存引闪设置中的全部选项，每次修改立即保存，下次开机恢复。不需要额外保存按钮。
- 对焦、引闪、主界面和回放组成一个安装包，在开机启动流程中加载，首次显示界面即生效；不得用开机后再次重载界面的方式替代。
- 本轮不研究补丁大小造成的时序影响，也不把跨升级保留、降级自动恢复作为当前开机整包的验收结果。
- “实时取景仅用于电子取景器”提示使用中央两行小框，24 像素字，左侧放 40 像素原厂信息图标；左右留白 20 像素、上下留白 16 像素、图文间距 16 像素。沿用原厂黑色背景和哈苏橙色边框，两秒后消失，不接管焦点或触摸。

## 已实现与验证

五点插值、数据校验、逐次拍摄冻结和 UI/worker 协议参数通路已加入候选源码。协议升级为 3，拒绝与旧版本混用。默认值与旧表全部档位一致，支持非单调标定值，检查非法范围、量化、未知档位和拍摄中参数隔离。离线业务与适配测试共 7054 项检查通过；没有物理时序测量。

EVF 提示单独在 `../evf-hint-r1`、`../evf-hint-r2` 生成与现有协议兼容的界面增量，不包含本目录未完成的标定协议。提示的模拟 UI 检查验证两行显示、触摸穿透、焦点保留和一秒隐藏；模拟截图不是相机页面实测。
