## 本次修正与现场事实

1. 原始传输的整行 base64 直接交给 awk 不适合目标 BusyBox。改用已验证的 `od -v -c → sed → awk → printf`，完整归档与 14 个成员摘要通过。上传证据：[stage.json](../build/sessions/replay-only-stage-20260912T163031831545Z/stage.json)。
2. 原始绝对路径白名单漏掉 `libstdc++` 的加号。补齐合法字符，保留 74 项基线摘要；74 个路径与 5 个拒绝用例通过。
3. 原始运行检查将任何 `(deleted)` 映射都拒绝。实机原厂 GUI 正常含 `rw-s` 的 `/dev/zero` 与 `/tmp/weston-shared-` 共享显示缓冲。只允许这两类非可执行映射的严格结构；其他删除映射继续拒绝。另有 7 项结构检查。
4. 目标 BusyBox awk 不能使用本次尝试的未转义 `/` 字符类写法。最终规则用固定字符串前缀与字母数字后缀，没有该兼容问题。
5. 前四次界面阶段均在 preflight 明确结束，没有创建安装状态或修改服务。修正后发现相机已经稳定待机；只重启一次原厂 GUI 服务。紧接重启的第一次检查早于 GUI 就绪而失败，后续只读观察确认 Active，未重复重启。之后进入正式界面与启用阶段成功。

以前失败的阶段、日志和证据均保留。派生小补丁没有重传整个回放包。固件分析及程序绑定为第一代 X1D-50c / 官方 1.25.0。
