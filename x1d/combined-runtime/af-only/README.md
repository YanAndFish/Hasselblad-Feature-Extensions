# X1D 仅 AF 临时装载

本目录执行用户指定的仅 AF 装载。固定来源为 X1D-50c 1.25.0，不包含引闪、回放增强或其他常驻 UI 模块。默认速度跟随原厂，两个提前量的动作尚未接通。未自动拍摄、对焦或试闪。

入口按用户后续指令调整为：

- 设置 → 自动对焦，在原厂选项下方的“AF 设置”。
- 参数页中央黑色区域的“AF 设置”快捷按钮。

两个入口共享同一 AF 页面。页面未打开时不查询；返回、导航离开或上下文失效时停止查询。自动对焦页使用原厂子页面导航，参数页关闭后回到原参数页。原厂主界面曝光正文逐字保留；参数页只追加快捷入口与页面打开时的导航保护。

## 离线与实机状态

资源及生命周期 48 项、实际 shell 恢复流程 26 项通过；新包 622 条传输/阶段命令均在固定帧界限内，真实 classic od 解码回读相同。测试中的相机接口和系统服务为替身，不能当作实机功能效果。

首次独立包的实机主界面、AF 页面编译及 GUI 健康保持通过。AF bus 服务虽然正常运行，但未创建配置端点；安装在 AF 内存请求前停止。原厂 GUI 和 bus 随后恢复，所有句柄关闭。证据分别位于 `../build/sessions/af-only-install-20260912T155843873591Z`、`../build/sessions/af-only-restore-before-ram-20260912T160217787064Z`。

旧设备目录已校验并保留在本次专属临时目录；新包使用 [独立通信修正版](../../af-experiment/camera-settings-r1/bus-startup-r2/REVIEW.md)，正在进行第二轮现场验收，尚不能视为 AF 安装完成。

## 执行和恢复

`build.py`、`package.py` 和默认 `session.py` 均离线。只有 `session.py --stage`、`session.py --install-staged <完整传输证据>` 进行设备操作，由主任务独占执行。Linux 先核原厂文件、进程和页面，再核新 bus 的阶段状态及真实端点；随后才进入 AF 的独立原厂申请、缓存验证和 14 个入口装载。

健康检查器沿用固定已验收产物及 20 分钟一次性窗口。完成 AF 的耐久日志审计后，协调器才释放安装保持。任何阶段不确定即停止，不重复派发，不把超时当作未执行。

有 AF 内存写入后，必须先依据对应恢复日志处理并核验原字节，才能撤销 Linux 消息消费者。完整安装的 AF 回滚使用通信修正版所绑定的独立装载入口；不释放保留的堆块。部分安装不能冒用完整安装回滚。
