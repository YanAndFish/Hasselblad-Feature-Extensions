# 稳定回放实机验收（未执行）

目标是区分“能装载”和“回放稳定、时延可接受”。执行者为持有当次硬件授权的主任务与用户；本任务不执行本页步骤。必须使用官方 X1D-50c 1.25.0 对应设备和 `stable-r1` 完整包；目标 Qt5.5、Storage、原 codec、GPU 均为真实组件。

前置条件：主任务已核对环境及会话所有权，完整包的 `ui` 和 `enable` 阶段明确成功，所有未使用设备句柄已关闭。图片由用户在其授权范围内选择，不将照片、文件名或设备序列号放入公开证据。没有读取照片授权时，由用户观察画面，记录匿名用例编号。

| 用例 | 步骤与成功判据 |
| --- | --- |
| 旧 JPEG 首次回放 | 从用户指定的冷启动状态进入既有 JPEG/3FR 配对图，检查图像和方向正确；记录按钮动作至第一张可见正确图像的时间。单独记录再次进入，不能把后者代替冷入。 |
| 普通浏览与放大 | 连续切换至少 20 张不同 JPEG，多次进入/退出 Full；检查细节、方向、预览底图和切换后的图像身份。记录 Full 动作至高分辨率正确画面的时间。 |
| 快速取消 | 在 Full 加载时换图、退出回放、重新进入；不出现前图残留、黑屏或持续不能响应。资源回落须由已获授权的匿名指标测量证实。 |
| 文件边界 | 分别检查没有完成记录的旧 JPEG、JPEG 不存在的 RAW-only 图，以及 JPEG 无法读取的受控用例。前者无需 RAW 读取；后者不能把一般 JPEG 读取失败误当缺失。没有合适授权或测试材料时保持未测。 |
| 拍后自动回放 | 由用户按正常流程拍摄；计时口径为拍摄动作结束至正确自动回放画面可见。独立于冷入与 Full 时延报告，并与相同设置的原基线比较。 |
| 显示与会话恢复 | 在获授权条件下检查 LCD/EVF 切换、正常待机后回放、退出装载会话后的原行为；不修改传感器、闪光修正或其他设置来迁就测试。 |

每步超过预先约定的超时，或出现黑屏、挂 logo、错图、服务失败时停止推进。不得通过自动重发安装或反复拍摄替代诊断。只由主任务处理其本轮创建的会话实例与临时目录；清理不触及照片、其他任务或其他会话。

证据需记录完整包摘要、匿名用例、开始条件、计时起止定义、执行者、实际结果、超时和清理结果。离线模拟耗时不能填入实机字段；未取得资源指标时不写“无泄漏”或“OOM 已修复”。
