## 固定输入与启动条件

- 协调任务明确指定目标 GUI/Qt/当前会话版本、设备独占时间、允许的安装及恢复动作；核对 GUI SHA256 和七个候选资源摘要。
- 先准备目标 Qt5.5 的无照片业务/provider 替身入口。它不绑定相机存储、相机控制、真实照片目录或原生控制端点；若不能实现此隔离，停止该阶段并报告缺口。
- 独立安装器、ARM Qt5.5 注册库、只读健康检查器和有限命令控制器已构建，冻结包及离线事务检查通过；目标业务/provider 替身可执行入口仍未实现。不能用生产 GUI 的正常装载代替合成隔离验收。
- GPU 及原厂 provider 的后续执行必须另行确认安全的合成缓冲/正常释放验证方式；未获授权不得为测试读取卡内照片、发出 FreeBuffer 或其他设备消息。

## 用例与证据

| 用例 | 驱动与判定 | 必须留下的证据 |
| --- | --- | --- |
| 两页面预建 | 正常 GUI 就绪后，LCD/EVF 各只有一个完整 MediaBrowseView；两个页面尚未呈现 | 对象身份、实例计数、零图像/ack/评级/BodySync 业务调用 |
| LCD 手动/自动回放 | 用合成模型驱动首次进入、退出、重入；即时预览转手动 | 同一页面身份；正确索引；ack 恰好一次；正常显示 |
| EVF 交接 | 合成 active 切换和指定/过期索引 | LCD 退出清图，EVF 索引有效；退出清状态并停预览计时；无双重 ack |
| 九宫格/单图/全图 | 合成 URL 驱动原 delegate、缩放信号及切图 | 对应图正确，退出源空；照片 delegate 销毁；存活 Shader.src 空 |
| 请求竞态 | 延迟图像回复；回复前退出、立即重入并选另一图 | 旧结果不能恢复旧画面；仅新会话图可发布 |
| 视频退出 | 替身延迟启动回复，分别在启动中和播放中退出 | 停止调用一次、计时结束、文件名清空，不改变真实视频系统 |
| 空目录/确认取消 | 空合成模型；带删除确认状态退出 | 没有删除/建目录调用；没有 null model 运行错误 |
| 重复生命周期 | 同一脚本连续 100 次进入/退出，各阶段等待事件循环和渲染提交 | 页面实例不增加；每轮照片引用归零；无累计活动请求或 GUI 错误 |
| 原厂缓冲/GPU链 | 后续单独授权的合成输入验证 | 原厂 factory/texture 引用归零、正常 FreeBuffer 与 GL 清理证据；不能只看 RSS |
| 性能与占用 | 同一软件输入、同一启动状态、相同模型/图像尺寸比较基线与候选 | 首次/重复呈现分布、稳态内存和高水位；标明样本数及计时口径 |

目标页面创建默认就绪超时 10 秒，单个合成图像步骤 5 秒，单轮退出观察 5 秒。超时算失败，不自动重新安装、重发业务动作或清理其他模块。GPU/provider 清理若依赖异步帧或服务回复，按实际状态记录；不能用等待到期证明内存已经释放。
