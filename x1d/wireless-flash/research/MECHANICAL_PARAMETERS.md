# 机械快门正式延迟参数

适用于本次已装入的专用实时线程版。用户指定：**每次准备开启、同一程序处理开启**。机械快门的正式规则是**固定档位查表，每档使用下表确定的延迟，运行时不做插值**。本文件记录正式选用值；没有据此修改相机设置或自动下发延迟。

| 机械快门 | 名义曝光时间 | 延迟 | 数值来源 |
|---|---:|---:|---|
| 1/125 s 及更慢 | 8 ms 及更长 | 5.00 ms | 用户范围归纳；1/125 s 边界按常值补齐 |
| 1/160 s | 6.25 ms | 5.00 ms | 两端均为 5 ms，常值补齐 |
| 1/200 s | 5 ms | 5.00 ms | 两端均为 5 ms，常值补齐 |
| 1/250 s | 4 ms | 5.00 ms | 用户指定；原始观察约 4.6 ms 开始受光 |
| 1/320 s | 3.125 ms | 5.57 ms | 插值计算 |
| 1/400 s | 2.5 ms | 5.98 ms | 插值计算 |
| 1/500 s | 2 ms | 6.30 ms | 用户指定：原估算 6 ms 加 0.3 ms 余量 |
| 1/640 s | 1.5625 ms | 6.56 ms | 插值计算 |
| 1/800 s | 1.25 ms | 6.75 ms | 插值计算 |
| 1/1000 s | 1 ms | 6.90 ms | 用户指定 |
| 1/1250 s | 0.8 ms | 6.90 ms | 用户指定 1/1000–1/2000 s 统一值 |
| 1/1600 s | 0.625 ms | 6.90 ms | 用户指定 1/1000–1/2000 s 统一值 |
| 1/2000 s | 0.5 ms | 6.90 ms | 用户指定 |

以下仅保留补齐表格时的计算依据，不作为运行时算法：按名义曝光时间进行分段线性插值，再四舍五入到 0.01 ms（10 µs），与当前界面调节步进一致。表格补齐后即使用各档固定值。设名义曝光时间为 T（ms），延迟为 D（ms）：

- T ≥ 4：D = 5。
- 2 ≤ T ≤ 4：D = 5 + 0.65 × (4 − T)。
- 1 ≤ T ≤ 2：D = 6.3 + 0.6 × (2 − T)。
- 0.5 ≤ T ≤ 1：D = 6.9。

这是对用户给定参数的插值，不是机械时序模型，也不是中间档位的实测结果。不外推至比 1/2000 s 更快的档位。高速段此前“六点几毫秒开始”的观察保留，正式选用值已由用户明确为 6.9 ms；正式选用值不等于开始受光边沿。当前批次未重新确认所选触发来源与闪光灯功率，不能把前述 1/4 功率设想写成已经验证的全表条件。
