# X1D 正式引闪：频道、ID、十六组与造型灯

本模块相机侧来源限定为 X1D 1.25.0。2026-09-12 已装入扩展运行包；装载成功与灯端/物理时序验证分别记录于 [正式运行程序](FORMAL_FLASH_RUNTIME.md)。不使用 X2D 地址或结论。

## 配置与分组

ID OFF 使用内部值 0，对应默认同步字 `0xc368`，不是省略整段同步字。ID 1–99 使用官方代码中的整数除法 `floor(0xc368 / (id+1))`，两个字节重复发送。A–F 对应协议地址 `0x0a–0x0f`，数字 0–9 对应 `0x00–0x09`。

频道通过 WiFi 中心频道与基带相位平移共同设置。相位表保留官方接收器完整频率字中的小数部分；CH5 的两个相位增量与先前用户观察到出光的版本逐位一致。此前仅按近似 2.5 MHz 中心值推导会丢失这部分差异，因此没有采用该近似值。

十六组各有 81 个手动功率值与一个 OFF 值，共 1312 种功率波形。每组造型灯开/关另有 32 种 `D3` 控制波形；引闪使用同一条广播 `B4 09`。总共 1345 个选择索引。功率 UI 范围仍为 1/256–1/1，实际灯支持的最低功率由灯型决定。

一次同步只提交一条广播引闪波形，不为每盏灯分别发送。分组开关与功率在之前通过逐组控制包发送；同一 CH/ID 下的接收灯按其当前组状态决定响应。广播不会携带十六份功率数据。

## 无线状态与取消

配置范围在 UI、进程间协议、无线客户端和 ARM 程序各层检查。进程间协议升级为版本 2、384 字节，旧版本包拒绝。切换配置先取消旧拍摄/试闪资格和未发送控制任务，等待已提交操作完成，释放旧通道，再设置新频道/ID、校验同步波形并就绪。

ARM 每次准备按当前配置计算预期波形哈希，并与生成后的样本读回比较；旧配置下准备的索引在更改配置时失效。同步提交路径沿用已准备的本地请求及专用发送线程，不在截止点临时编码。原厂 PHY 准备、原有等待及清理保留，固定发射增益仍为此前版本的设置。

试闪先发送全部十六组快照，包括 OFF，全部关闭时不广播。关闭“发送功率更新”后不会偷偷补发控制包；只有本会话已经完成全部分组开关发送且状态一致，才允许直接广播。这个检查不提供无线接收 ACK，也无法得知用户在灯上独立更改的状态。

当前扩展版已通过相机内组件/资源/驱动检查。扩展频道、灯端造型灯、十六组接收和曝光效果尚未完成新的实机验收；没有新增物理频率或时序测量。
