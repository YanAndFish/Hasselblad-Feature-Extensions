# 第二个 B 帧同步：当前接入障碍

用户要求给同一次拍摄的第二个同步周期增加引闪选项。这里不将跨帧积分称为两次独立拍照。当前机身已安装的 GFS2 三选项保持原样，本轮没有相机请求或安装。

来源仍为官方 X1D 1.25.0 的固定 FPGA 局部模型；输入哈希随报告保存。离线程序为 `research/check_second_b_sync.py`。

## 本轮实际复核

在 H2582/V8 的合成案例中，B 首次低电平从模型周期 16 持续到 2635，第二次开始于 20672；同步保持位首次在周期 18 变高。

在周期 20 清除保持位、24 解除清除时，保持位在 25 又变高，但 B 仍处于第一次脉冲。因此“清掉第一次标志后再等到变高”会把同一次同步误认成第二次。此方法不能作为第二个 B 的触发条件。

改在周期 4000 清除、4004 解除时，保持位到 20674 才再次变高，与第二个 B 脉冲相符。但是目前 ARM 端没有已核实的 B 即时电平或帧序号读取接口，无法直接使用这个模型上的已知脉冲结束条件。硬编码等待不能标称为真正的第二次同步。

上述控制写入将启动命令 bit 0 保持为零、运行控制 bit 1 保持为一时，135 个原有时序状态逐周期一致；若重复写 bit 0 为一，部分原状态已经产生差异。即使局部对照相同，也不等于完整 AXI、传感器电气或实机行为已验证。

## 尚未具备的接入条件

需要可读取的 B 当前电平、可信帧计数，或另一种能证明首脉冲已经结束的条件。目前起止同步计数属于接收数据流，尚未证明等同于这里的 B 输出周期，不直接借用。

因此本轮没有把“第二个 B”加入机身可选触发源，也没有改动当前三个已安装选项。完整复核数据见 `build/farm-sync-capture/second-b-clear-review-20.json` 与 `second-b-clear-review-4000.json`。这些是模型周期，不是实测时间。
