# 电子快门自动引闪临时规则

本版为 GFS3，依据用户本机实拍的近似时序，尚未完成新版实拍验证。仅临时装载，关机失效。机械快门待后续处理。

## 固定计算

每张电子快门照片使用本次曝光参数 T（微秒），扫描估值为 295000 微秒：

- T ≤ 250000：延迟为 590000 − (295000 + T) / 2，目标为亮区居中。
- 295000 ≤ T ≤ 500000：延迟为 890000 − (295000 + T) / 2，目标为全开区中点。
- 超过 500000、零值、高 32 位非零、两个分组间未覆盖值：不自动引闪。

延迟取最近毫秒，基准沿用用户调试实拍时的 B 消息 Linux 接收时刻。不是 FPGA 与 Linux 时钟的直接换算，毫秒取整不代表实测精度。不改变原厂动态闪光补偿。

## 本次曝光参数来源

静态来源仅限官方 X1D 1.25.0 FARM，SHA-256 `317841f6f4dff599cda8c83f2b4912f78534db20e7690d0b14b0cd5f1b8c39ca`。

原厂电子快门函数在 `0x1c3fb0` 调用 `0x1cd390`，随后 `0x1c3fb4` 将 64 位结果保存于 `[fp-0x74]`。该 getter 读取 `0x2add38` 的 64 位参数。该栈位置在本函数中只有这一处写入；B 采样点 `0x1c4380` 已处于其后，不轮询可变化的全局快门设置。原厂 `0x1c43b8` 再取该值并除以 1000，参与曝光等待时限计算。其低位也由 `0x1c3fc8 → 0x20faa4 → 0x20688c → 0x2063f8` 用于本次配置。

新采样包装读取上述两个栈字，随同次 shot 的 B 消息发出；保留原寄存器、状态位和原厂后续指令。GFS3 消息扩至 44 字节，内部 IPC 为 64 字节；新版本标识拒绝与旧 GFS2 混用。

## 界面与执行

Wi-Fi 设置页入口为“电子快门引闪（临时）”。保留自动开关、无线功率与单次试闪；删除电子快门节点、进度门限和手动延迟控制。worker 固定使用 B，同次进度与正常停止消息不参与自动引闪。自动默认关闭，用户开启后才生效。

新拍摄撤销旧待发请求；同次 B 只消费一次；不支持的曝光不能复用上一张计算结果。自动关闭、设置变化、界面失联、同步来源变化仍撤销待发。单次试闪为用户独立操作。

## 离线验证

两个 ARM 地址布局各 14 项测试已通过，包含同次曝光两个字的传递、新拍摄替换、寄存器保持、队列失败及调用者限制。装载模型 6 项测试通过，覆盖 1466 个写入前后故障位置。自动公式遍历 500000 个微秒输入并检查舍入；截止时间、一次消费及关闭取消测试通过。消息解析、事件核心、桥接及无线帧测试通过。

这些结果不代表本版已经装入或通过实拍；安装状态以本次安装证据为准。实际光带位置仍待用户验证。
