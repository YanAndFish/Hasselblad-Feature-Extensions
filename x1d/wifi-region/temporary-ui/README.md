# X1D 临时热点界面

## 新设置页候选（2026-09-22 后续）

- `PagePool.qml` 按主菜单入口保留对象，系统就绪后串行预创建主菜单页面；其他列表页面首次进入才创建、退出后保留复用。预加载不会主动点击控件或调用设置写入。当前仅 RAM 候选，持久化开机验证尚未完成。
- 离线主菜单测试确认同一快捷页二次进入对象身份不变、非快捷页不被预加载。滑入保持原时长，改用快速起步曲线。旧通用页明确限制为纵向列表滚动，补左边缘返回手势；完整区域实机右滑仍待用户验收。

- `SettingsPage.qml` 为独立绘制和手势页面，普通行按五行视口、主文字 32、分组标题 24；分组及说明占额外高度。`NativeSettingsPage.qml` 使用原设置目录、代理和条件，显示值改变时更新列表。
- `DirectMainMenu.qml` 只把类型及操作已适配的普通设置页路由至新页；特殊操作、无代理项目、无线和取景专用选择器仍保留旧页。**不是全部原厂页面已经替换完成。**
- 离线验证覆盖独立页开关事件、右滑返回、适配器模拟代理写入及弹窗请求；不能代替真机功能、写卡或重启保存验收。
- 引闪列表改为四个完整行，底部仍保留试闪、选择分组、设置与文字标签。共用头部增加灰色竖线；曝光摘要为一整格。参数页缩放仅影响符号，点击区域保留。
- JPEG 回放替换和强制 RAW＋JPEG 尚未实现到此候选；旧 reader 候选自带缓存及资源管理，不能直接作为“沿用原厂缓存策略”的实现。

### 后续实机反馈与局部修正

- 引闪和普通设置开关统一使用 `SettingsToggle.qml`，保留原有业务约束（功率更新在基线中强制开启）；不把外观一致描述为原厂控件复用。

- 分区标题改用原厂 `MainScreen` 翻译上下文；测试译者按上下文区分，防止此前跨上下文假阳性。整套语言切换仍需真实语言逐项检查，不能标记全部完成。

- 后续布局：滑条改为标签下一整行，保留原有绘制；选择值按标签自然宽度分配剩余空间并右对齐。张数区域左边新增灰色竖线，左侧留空。

- 最新引闪外观要求覆盖旧的“底部保留文字”：底部试闪、选择分组、设置仅显示居中图标，顶部无线状态文字保留。底部三格按原参数页最小格宽 100、外侧留白 13 布局，CH/ID 水平居中。引闪列表分隔线扩展到全宽，设置及选择分组顶部恢复横线。宿主触控回归通过，最终显示以实机反馈为准。
- 图标尺寸使用固件资源可见像素而非外框比较：`settings_icon.png` 是 125×80、可见约 76×76，原 46 方框显示时齿轮只有约 28 高；调整外框到 74，试闪到 46，分组线图放大 1.4 倍。顶部无线按钮仅在引闪调用点启用 76×82 居中布局、45 图标与 18 字号；其他调用保留默认尺寸。

2026-09-22，用户授权做临时联网界面并装载到相机内存。基线为 X1D-50c 1.25.0、Qt 5.5.1。最初独立 Wayland 窗口进程运行但用户看不到，已停止；当前改为在原 GUI 内嵌页面，Wi-Fi 设置页右下角显示入口。没有替换持久程序或安装包。所有机内载荷位于 tmpfs `/run/hbl-hotspot-ui`。

## 试用

先把相机原有无线模式设为关。打开测试窗口后点启用客户端，再扫描；点热点填入名称，用屏上键盘输入 WPA2 密码，再连接。暂不支持企业认证、WPA3-only 或开放热点。状态区区分关联与获取地址，取得地址不代表互联网验证通过。

密码不写入配置文件：在进程内派生 PSK，经仅限本机的 Unix socket 提交给 wpa_supplicant；不调用保存网络配置。退出时删除临时网络，停止本轮连接进程并恢复保存的无线状态。启动脚本也会在窗口退出后尝试恢复。异常断电后 tmpfs 自行清除。

恢复和联网故障场景尚未完整实测。程序没有实现云端调用、照片读取、打印或重启相机。连接过程中不要操作原来的无线模式菜单，以免两个控制流程冲突。

## 三行四列主菜单与引闪详情候选

- 首页依次为：曝光、对焦、画质、图像；闪光灯、显示、电源、存储；空、Wi-Fi、设置、空。`DirectMainMenu.qml` 直接加载目标页，不创建中间分类页。设置列表按相机、视频、通用分区，并过滤首页已有入口及手动对焦独立入口。
- 自动对焦页加入手动对焦配置，显示标题为“对焦”，各设置原有代理和适用条件保留。
- 首页入口返回首页，列表入口返回列表；关闭页面时先播放原有时长动画，再停用页面。已替换的旧分类页不再后台预加载；尚未获得旧页面逐页实例化耗时排名，不能宣称已证实开机性能改善。
- 引闪列表五行行高与吸附步长同时调整，内部控件使用完整行高居中；状态文本使用第五行内部的下部空间。详情页组名字母固定在 M/OFF 下方，不随功率文字宽度移动，隐藏底栏。专用横向滑条调用既有 swipePower；外部上下滑切换可见组，横滑返回。相邻组预览随拖动进入，松手完成滑动再更新组索引，内容裁剪在 CH/ID 栏下方。选择分组页底部空白区域纳入返回手势。
