# 用户确认后的剩余重做范围

本轮用户逐项审阅清单后，将剩余完整页面重做限定为以下三项：

| 页面 | 当前状态 | 完成要求 |
|---|---|---|
| 拍摄参数主页 | 原厂 ControlScreen 改布局，未完整替换 | 使用自己的页面；沿用已认可布局、格宽、字号、状态绑定和操作功能；开机准备并复用 |
| 手动照片回放 | 用户已撤回 JPEG 自绘回放方案 | 保留先前的原厂优化 RAW 回放；其双击放大偶发只显示缩略图的问题仍待单独验证 |
| 拍摄后自动回放 | 用户已撤回 JPEG 自绘回放方案 | 不启用新回放资源，不改变现有原厂回放路径 |
| 实时取景界面及对焦框（后续新增） | 2026-09-22 本地候选已加入自绘常驻 HUD 和对焦框，拖动预览跟手、松手提交一次；尚未装机 | 保留原厂画面传输、测光和对焦接口；继续核对取景特殊状态、裁切、缩放、EVF/LCD 切换及实机触控；不得把离线通过说成实机完成 |

白平衡工具、日期时间、水平仪、许可、认证，以及清单中的选择框、维护、格式化、自定义模式确认和提示组件，用户明确同意继续沿用原厂实现，不再作为重做缺项。已经自绘的普通设置页保持现状；仍需处理实际功能缺陷时不以重做全部页面为前提。

后续用户修订：滚动选项框改为自己的组件，包括设置页、引闪步长以及参数页光圈、快门、ISO；外观与原厂一致，必须保留中心选中区域、靠近中心放大/离开缩小、上下渐隐、原厂尺寸和滚动参数。维护等确认弹窗仍沿用原厂。本轮还修复设置选值后滚动位置重置，改用保留条目的 ListModel。是否已装载以 build/ui-deployment.json 和实际回读为准。

回放继续沿用当前原厂优化 RAW 路径，JPEG 自绘回放资源在候选包中关闭。画质锁定 RAW 加 JPEG 的状态以当前相机资源回读为准；写卡顺序只分析，不实施。

当前取景候选由 `build_flash_preview.py --lock-format` 打包，`check_viewfinder_ui.py` 的主机模拟验证已通过，原厂 RAW 回放 QML 与 R40 基线字节一致。2026-09-22 本轮装载遇到 `USB_NOT_PRESENT`，相机端尚未更新；实机触控、取景显示和功耗都没有据此宣称已验证。

验证后装载到相机临时内存，不写入持久固件。合成图片和模拟目录用于离线验证；不因本清单授权自动拍照、读取用户照片或执行格式化等操作。
