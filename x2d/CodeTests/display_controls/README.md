# Display Control Design Scope

The design manages display state through mode changes, timeouts and exit restoration, stopping unnecessary background refresh after leaving the relevant mode. The public addition retains only this generic design note, without manufacturer display interfaces, menu assets or deployment scripts.

This directory claims no independent on-device runtime capability. Other independently testable algorithms are listed in the root `PUBLIC_UPDATES.md`. See [index](../../../README.md).

---

## 中文

研究实现采用模式切换、超时和退出恢复来管理显示状态；退出相应模式后停止无必要的后台刷新。公开更新只保留这项通用设计说明，不提供厂商显示接口、菜单资源或装载脚本。

没有对本目录声明独立设备运行能力。其他可独立验证的算法与组件见仓库根目录 `PUBLIC_UPDATES.md`。
