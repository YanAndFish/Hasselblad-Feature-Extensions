- 用户要求尽量减少脚本、目标接近原厂／20ms 或更低、与原厂界面更早并行准备，随后表示拔下 USB。本段工作没有访问相机，也没有替换相机当前开机文件。
- `native-input-candidate` 已生成原生常驻控制库及独立加载候选，编译与离线检查通过；去除切换热路径外部命令，提前建立通信连接，回调间隔候选为 5ms。一次性开机地址解析仍使用脚本。启动触发提前与实际窗口就绪等待均未实机验证。
- 56 个状态决策、7 个构造函数拒绝场景、9 个 ARM64 回调场景通过；不代表完整原生循环、D-Bus ABI、权限、首帧绘制或开机行为已经通过。
