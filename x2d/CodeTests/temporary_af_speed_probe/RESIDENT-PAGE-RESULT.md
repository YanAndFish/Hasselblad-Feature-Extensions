# X2D 前键常驻预览：实机结果

2026-09-24，第一代 X2D，原厂 4.2.0。

本次将每次按键新建图片测试进程的实现换为常驻窗口。修改仅在独立预览进程的运行内存中；原厂文件没有改写。原厂 GUI 的前键功能映射仍只在运行内存里临时设为 None，退出桥接时恢复原值。

## 已验证

- `build_resident_page.py` 的九组 ARM64 指令模拟通过，包含显隐、无窗口、多窗口、退出及槽对象销毁；回调所在内存页以 RX 权限模拟，回调不写该页。
- 实机独立预览进程成功预先创建图片窗口，首次计时回调隐藏窗口，此后每 20 ms 检查显隐请求。此间隔不是按键端到端延迟的测量值。
- 同一进程、同一窗口的显示状态依次回读为隐藏、显示、隐藏；过程中没有重建 GUI 进程。
- 已装入常驻按键监听：只响应 AF/MF 实体键 DOWN，忽略 UP 和重复事件；每次按下切换显隐，不自动退出。
- 安装后日志已有六次交替显隐请求，预览进程仍为安装时同一进程，最终窗口隐藏。原厂 GUI 与相机服务存在，原厂 GUI 和预览进程的 TracerPid 均为零。
- 实际按键体感、端到端延迟和隐藏后相机操作流畅程度仍需用户观察，不能把显隐状态回读等同于屏幕显示耗时实测。

## 实现与退出

`resident_page.S` 仅替换独立 `--imagetest` 进程的定时退出槽，将其改为 Qt 事件线程内的显隐检查。读取窗口列表并确认恰好一个窗口，调用原厂 QWindow 显隐方法；已有显示状态与目标一致时不重复切换。没有新增对焦或无线操作。

安装结果和运行地址在 `resident-install-result.json`。地址只对本次进程有效，不得跨重启复用。

`Restore-ResidentPage.ps1` 请求停止桥接，终止独立预览进程，并在原厂 GUI 身份和按键映射仍匹配时恢复原绑定。原厂界面进程重启或相机关机后，运行内存修改失效。暂存文件位于相机 `/tmp/afmf-resident`。

两个蓝绿按钮仍是图片图案，不是可点击控件。常驻显隐不代表任意自定义 QML 已可加载。
