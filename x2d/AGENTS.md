# X2D 专属资料规则

继承项目根目录 [AGENTS.md](../AGENTS.md) 及其中引用的跨项目基础规则。先读 [X2D 索引](README.md) 与 [历史交接](research/history/RESEARCH_HANDOFF.md)，再按当前用户指令确定权限；历史文档中的旧批次授权不能用于新设备操作。

- 本目录只放第一代 X2D 100C 资料。当前固定分析版本为 4.2.0；其他固件版本单独建目录，符号、地址、哈希必须绑定版本。
- 新研究文档、离线脚本、验证和输出按本目录 README 分类。后续本任务不得再把新增 X2D 专属研究成果散放到根目录。
- 根目录共享客户端、工具、缓存与证据数据依赖见 [共享项索引](SHARED_ITEMS.md)。没有具体任务授权，不改动它们；不得为了迁移而盲目修改程序路径或重新运行硬件工具。
- `research/history/` 保存旧正文。更新当前结论时另写版本目录中的文档，不覆盖历史实机结果；旧路径短索引继续保留。
- 不修改 `x1d/`。不得套用 X1D 地址、镜像或补丁作为 X2D 已验证事实。
- 目录整理授权不新增相机连接、枚举、配置写入、重启、射频装载、拍摄、闪光或固件操作授权。离线回读模型不得被表述为客户端已实现或实机已通过。
- 不保存凭据、密钥材料、设备序列号或照片信息。
