# Hasselblad Feature Extensions

独立、非官方的相机功能扩展源码项目。首批提供可独立验证的界面与离线组件；不代表厂商认可，也不提供可直接安装的完整相机更新。

## 首批内容

| 目录 | 内容 | 验证范围 |
| --- | --- | --- |
| [X1D 动画与声音策略](x1d/shutter-effects/README.md) | 程序绘制动画、声音路由状态策略 | 九项替身策略测试通过；不含音频和设备播放器 |
| [X1D 离线资源工具](x1d/offline-resources/README.md) | 文本资源读取和生成 | 四项自造数据测试通过；不含厂商资源 |
| [X2D 引闪界面](x2d/flash-ui/README.md) | 分组、功率、设置界面的离线组件 | 自绘图标、系统字体；五个页面切换与图标加载通过 |

X2D II 后续按已核对材料补充，X1D II 尚待收到实现；没有用其他机型代码替代。完整更新生成、装载与对焦适配不在首批范围。被暂缓的材料不放在本项目隐藏目录或历史中。
